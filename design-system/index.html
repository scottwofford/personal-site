Design System

The site's existing look, written down. Codified from styles.css and home.css, not a redesign.

Everything below is what the site already renders. The machine-readable version lives in /tokens.css as CSS custom properties.

Palette

One dark canvas, one raised surface, a gray text ramp from bright to faint, and a single blue accent.

#1a1a1abg: page background
#252525surface: code, callouts, table headers
#333border: rules, tables, h2 underline
#444border-strong: blockquote edge
#ffftext-bright: h1, h2, strong, hover
#e5e5e5text: body default
#ccctext-h3
#bbbtext-body: paragraphs, lists, cells
#999text-secondary: em, quotes
#888text-muted: section names, nav
#666text-faint: subtitles, dates, subtle links
#6b9fffaccent: links
#8bb4ffaccent-hover: button hover

Typography

One font: Inconsolata (Google Fonts), weights 400 and 600, monospace fallback. Content pages use line-height 1.35; the homepage tagline uses 1.7.

Display2.6rem, 600 - homepage h1
Heading 11.8rem - content page title
Heading 21.3rem - section, with #333 underline
Heading 31.1rem - subsection
Body text1rem
Small0.9rem - code, quote attributions
Table / meta0.85rem - tables, sibling nav, dates

Spacing, radii, layout

  • Spacing rhythm: 0.25 / 0.5 / 0.75 / 1 / 1.5 / 2 rem
  • Radii: 3px inline code, 4px blocks and cards, 8px images
  • Content column: max-width 900px, centered, 2rem padding (1.25rem under 768px, 1rem under 480px)
  • Hover transitions: 0.2s (0.15s on dropdown links)

Components in use

Section nav

Every content page opens with ← home / section in faint gray, plus a sibling row at 0.85rem when the section has more pages. The current page shows white.

Subtitle

Italic, faint gray, directly under the h1. This line is one.

Blockquote

3px #444 left border, indented, italic, secondary gray.

- attribution in .quote-attr, 0.9rem faint

Table

Header#252525 background, white, 600
Cell#bbb on #1a1a1a, #333 borders, 0.85rem

Code

Inline code on the #252525 surface, 3px radius. Blocks:

pre { background: #252525; border-radius: 4px; }

Callout

.callout: surface background, 4px radius, 1rem padding.

Button

The one button on the site (blog subscribe): accent background, page-background text, 4px radius.

Homepage-only patterns

  • Top nav: right-aligned, muted gray links, hover dropdowns on a #252525 panel
  • Expand toggle: 28px square button revealing all dropdowns inline
  • Language flag: fixed top-left, half opacity until hover
  • Hover previews: images that appear beside links, 8px radius, soft shadow

Deliberately different pages: the Luthien landing mockups (luthien/landing_v8/, Inter + JetBrains Mono on near-black) and the kids' pages in shared/ (Comic Sans on pastel gradients). Everything else should converge on the system above.
